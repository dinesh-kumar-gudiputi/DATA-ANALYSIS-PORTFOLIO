# 🛒 Supermarket Sales Analysis

## 📌 Overview

This project analyzes supermarket sales data to uncover:
- revenue trends
- customer behavior
- product performance
- payment preferences
- branch performance

The analysis was performed using Python, Pandas, Matplotlib, and Seaborn.

---

# 📂 Dataset

Dataset contains:
- sales transactions
- customer information
- product categories
- payment methods
- gross income
- ratings

---

# 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

---

# 📊 Analysis Performed

- Sales by branch
- Monthly revenue trends
- Product line analysis
- Customer segmentation
- Payment analysis
- Gross income analysis
- Correlation analysis

---

# 📈 Key Insights

- Branch C had highest total revenue.
- E-wallet was most preferred payment method.
- Top product lines contributed majority of revenue.
- Member customers generated more sales.
